# Walking Dashboard

A one-page dark dashboard of my Apple Watch walks, styled after the Activity Rings. See `../plan.md` for the design decisions.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production build into dist/
```

The data in `src/data/` is generated by `../scripts/export_dashboard_data.py`; don't edit it by hand.

Filters are stored in the URL, e.g. `http://localhost:5173/?year=2026&season=Summer&day=Sat,Sun`.

## Structure
- `src/App.tsx`: page layout (Overview → Trends → Habits → Detail → Data validation)
- `src/state/FiltersContext.tsx`: filter state and filtered walks, synced to the URL
- `src/lib/`: filtering, aggregation and formatting helpers
- `src/components/`: filter bar, Activity Rings, KPI tile, chart card, heatmap, tooltip
- `src/charts/`: one file per chart
- `src/theme.ts` / `src/index.css`: Activity Ring colours and dark tokens
